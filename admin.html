安全边界

为什么没有“后台密码”

纯静态网页中的密码、哈希或管理员账号都会被下载到访客浏览器，因此不能作为真正的访问控制。

本管理页把“编辑界面”和“写入授权”分开：任何人都能打开编辑器，但只有拥有 GitHub 写权限令牌的人才能提交修改。

如果你以后想做真正的账号后台，可以再接 Cloudflare Access / Pages Functions；当前方案已经覆盖个人博客常见维护需求。
